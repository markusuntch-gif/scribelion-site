# ScribeLion public website

Static support and privacy pages for the ScribeLion iOS beta. No app source,
audio, transcripts, credentials or build artifacts belong in this repository.

Publication source: `main`, repository root, GitHub Pages.
Expected project URL: https://markusuntch-gif.github.io/scribelion-site/

Publish only: `index.html`, `privacy.html`, `support.html`, `site.css`,
`.nojekyll`, `README.md`. Use system fonts and no scripts or analytics.
The privacy policy applies to ScribeLion, not CopyLion. Beta distribution is
separate from publishing this site.

Before a release, compare live HTTPS responses byte-for-byte with the approved
source commit and keep the build/verification record in the private app project.
Changes to app data handling require reviewing the policy again.
